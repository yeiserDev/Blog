            Cómo anotar la próxima reunión para mantener el archivo

            Todo vive en el arreglo REUNIONES, al inicio del <script>. Agrega un objeto al final y la fecha aparece sola en la línea de tiempo: 

            {
  n: 3,
  fecha: '2026-11-12',
  hora: '9:00 pm',
  titulo: 'Constitución y primera cotización',
  estado: 'realizada',      // o 'programada'
  quienes: ['Aldair', 'Yerson', 'Leonardo', 'Yeiser'],
  entrada: 'La reunión en una línea.',
  decisiones: [ { e: 'ok', t: 'Lo que quedó cerrado.' } ],
  cabos: [ { e: 'open', t: 'Lo que quedó debiendo.' } ],
  relato: [
    { p: 'Un párrafo de lo que pasó.' },
    { h: 'Un subtítulo' },
    { cita: 'Algo que alguien dijo.', de: 'Yerson' }
  ],
  observacion: 'Lo que el que anota piensa.'
}

            Estados: ok cerrado, wip en curso, open abierto, warn atención. Cada uno lleva su palabra y su forma, así que no dependen del color.
